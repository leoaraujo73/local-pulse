## 📰 Atualizar notícias
1. Entre no repositório no GitHub.
2. Abra o arquivo `noticias.json`.
3. Clique no **lápis** (editar).
4. Adicione ou altere notícias neste formato:

```json
{
  "id": "eco-004",
  "categoria": "Economia",
  "titulo": "Título da notícia",
  "descricao": "Resumo curto",
  "conteudo": "Texto completo da notícia...",
  "data": "2025-09-08",
  "link": "https://exemplo.com"
}
